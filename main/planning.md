# 项目扩展方向

## 当前你已有的

```
ESP32 + ILI9341 LCD + 3按键 + WiFi
├── WiFi 扫描列表
├── 选择连接
├── SmartConfig 配网
└── 状态机架构
```

---

## 扩展路线图

### 第一阶段：完善现有功能（简单）

```
1. WiFi密码输入
   ├── 现在密码是硬编码的
   ├── 加一个虚拟键盘界面
   └── 用状态机管理：LIST → CONNECTING → KEYBOARD → CONNECTING

2. WiFi信息详情页
   ├── 选中WiFi后按ENTER显示详情
   ├── SSID、BSSID、信道、加密方式、信号强度
   └── 状态：LIST → DETAIL → CONNECTING

3. 信号强度可视化
   ├── 把 -XX dBm 转换成信号格数
   ├── ████░ -30dBm
   ├── ███░░ -50dBm
   └── █░░░░ -70dBm

4. 自动刷新
   ├── 定时重新扫描（比如30秒一次）
   ├── 新WiFi出现时提示
   └── WiFi消失时自动移除
```

### 第二阶段：加传感器（中等）

```
5. 温湿度监控
   ├── 加 DHT11/DHT22 传感器
   ├── LCD 实时显示温湿度曲线
   ├── 超温报警
   └── 新增状态：MONITOR

6. 环境监测站
   ├── 加 BME280（温湿度+气压）
   ├── 加光敏电阻
   ├── LCD 显示多传感器数据
   └── 数据记录到 SD 卡

7. 空气质量检测
   ├── 加 MQ-135 或 PMS5003
   ├── PM2.5 / CO2 显示
   ├── 颜色报警（绿/黄/红）
   └── 新增状态：AQI_MONITOR
```

### 第三阶段：联网功能（进阶）

```
8. HTTP 服务器
   ├── ESP32 连上WiFi后启动Web服务器
   ├── 手机浏览器访问 192.168.x.x
   ├── 网页显示传感器数据
   └── 网页控制 ESP32（开/关/设置）

9. MQTT 上报
   ├── 传感器数据通过MQTT上报
   ├── 对接 Home Assistant / 阿里云IoT
   ├── 远程查看数据
   └── 远程下发控制命令

10. NTP 时间同步
    ├── 联网后自动获取时间
    ├── LCD 显示实时时钟
    └── 传感器数据带时间戳
```

### 第四阶段：存储与OTA（产品级）

```
11. NVS 配置存储
    ├── WiFi密码保存到 Flash
    ├── 下次开机自动连接
    ├── 不用每次都配网
    └── 用状态机：BOOT → AUTO_CONNECT → LIST/CONNECTED

12. OTA 升级
    ├── HTTP OTA：手机传固件给 ESP32
    ├── LCD 显示升级进度条
    ├── 升级失败自动回滚
    └── 新增状态：OTA_UPDATE

13. SD 卡数据记录
    ├── 传感器数据保存为 CSV
    ├── 可以导出到电脑分析
    └── 循环写入，满了自动覆盖旧数据
```

---

## 我的建议：按优先级排序

```
推荐顺序：

 1. WiFi密码输入      ← 最实用，解决硬编码问题
 2. NVS自动连接       ← 用户体验提升巨大
 3. HTTP服务器        ← 手机随时查看，不用一直看LCD
 4. 加个传感器        ← 项目有实际用途
 5. MQTT上报          ← 对接云平台
 6. OTA升级           ← 产品级功能
```
